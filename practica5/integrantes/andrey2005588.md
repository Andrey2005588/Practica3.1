# Cambio de Acción Referencial - Andrey2005588

Elegí la relación **Clase -> Sala**. Originalmente tenía `ON DELETE RESTRICT`.
Cambié la acción a `ON DELETE CASCADE` en una copia de la base.
Al borrar la Sala 1, se borraron automáticamente las clases asignadas a ella. 
**Conclusión:** Para nuestro dominio, `RESTRICT` es la opción correcta. No debemos permitir que borrar una sala destruya el registro histórico de las clases. El gestor debe impedir el borrado hasta reubicar las clases.
